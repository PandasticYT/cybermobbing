# cybermobbing – „Was würdest du tun?“

Interaktive React/TypeScript-Webseite zum Thema Cybermobbing mit datengetriebener Messenger-Simulation.

## Tech-Stack

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Entwicklung

```bash
npm install
npm run dev
```

## Qualitätssicherung

```bash
npm run test
npm run build
```
